Privacy Policy — tube-autopilot

Last updated: 2026-09-15

1. What the app does

tube-autopilot is a personal automation tool that publishes short-form videos to YouTube on behalf of its owner (the same person who authorized it) through the official YouTube Data API and OAuth 2.0. It uses this connection only to upload videos and thumbnails to the owner's own channels and to read basic public statistics of those same channels. It does not read, modify, or store information about other people.

2. What information is handled

  • YouTube account access: granted by the owner via Google's OAuth consent screen. Tokens are stored only in encrypted, access-restricted private storage (GitHub Actions secrets) and never shared publicly.
  • Video content: scripts, voice-over audio, and rendered videos are generated by the app itself and uploaded to the owner's channels.
  • No third-party personal data is collected, processed, or sold.

3. Where data lives

All credentials and generated content live on the owner's own infrastructure (their GitHub repository, its encrypted secrets) or on YouTube itself. The automation runs on GitHub's servers.

4. Third-party services

Google / YouTube (YouTube Data API) and GitHub (GitHub Actions), each governed by their own policies.

5. Contact

This is a personal, non-commercial automation project. The owner can be reached through the GitHub repository that hosts this project: Hablhabl334/tube-autopilot.
